# Gestor de Tareas

Aplicación web para agregar, editar, completar y eliminar tareas, desarrollada con HTML, CSS y JavaScript (ES6+ y programación orientada a objetos).

## Funcionalidades

- Agregar tareas con validación (no vacías, mínimo 3 caracteres, máximo 100, sin duplicados).
- Editar tareas en línea (Enter guarda, Escape cancela).
- Marcar tareas como completadas.
- Eliminar tareas con confirmación.
- Las tareas se guardan en LocalStorage y permanecen al recargar la página.
- Diseño responsivo para escritorio, tableta y teléfono.

## Estructura

```
index.html   Estructura de la página
styles.css   Estilos y diseño responsivo
app.js       Clases Tarea y GestorDeTareas, manipulación del DOM y eventos
capturas/    Capturas de pantalla del funcionamiento
```

## Cómo ejecutarlo

Abre `index.html` en el navegador o usa la extensión Live Server de Visual Studio Code.
